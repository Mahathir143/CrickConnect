2. Pure State Projection: The Event Sourcing Engine

Rather than persisting mutable accumulators, every ball is stored in an immutable event array. The live match snapshot is computed on each event:

export function computeMatchSnapshot(
  matchInfo: MatchMeta,
  ballEvents: MatchBallEvent[]
): LiveMatchSnapshot {
  let score = 0;
  let wickets = 0;
  let legalDeliveries = 0;
  let isFreeHitActive = false;

  // Track striker, non-striker, bowler spells, partnerships
  for (const event of ballEvents) {
    const totalBallRuns = event.batsmanRuns + event.extraRuns;
    score += totalBallRuns;

    if (event.isWicket) {
      wickets++;
      // Handle batsman dismissal and new striker placement
    }

    if (event.isLegalDelivery) {
      legalDeliveries++;
      isFreeHitActive = false; // Free hit expires after a legal delivery
    } else if (event.extraType === 'NO_BALL') {
      isFreeHitActive = true;  // Free hit triggered or carried forward
    }

    // Strike rotation on odd runs (1, 3, 5)
    if (event.batsmanRuns % 2 !== 0 && !event.isWicket) {
      swapStriker();
    }

    // End of over: 6 legal deliveries swap ends
    if (legalDeliveries > 0 && legalDeliveries % 6 === 0 && event.isLegalDelivery) {
      swapStriker();
    }
  }

  return {
    score,
    wickets,
    overs: `${Math.floor(legalDeliveries / 6)}.${legalDeliveries % 6}`,
    isFreeHit: isFreeHitActive,
    crr: calculateCRR(score, legalDeliveries),
    // ... complete calculated snapshot
  };
}

Infallible Multi-Level Undo Mechanism

When the scorer clicks Undo, the system executes ballEvents.pop() and invokes computeMatchSnapshot(). In 0.2 milliseconds, the exact state of striker, non-striker, current bowler, and over ball timeline is flawlessly restored without numerical errors or manual corrections.

3. Modern ICC Rulebook Implementation

Rule Scenario ICC Specification CrickConnect Automated Behavior
Caught Dismissal Strike ICC Law 18.11 (Oct 2022 onwards) The new incoming batter automatically assumes strike at the striker's end, regardless of crossing before the catch was completed.
Run-Out on Striker / Non-Striker Disambiguate runner and strike Scorer modal asks who was dismissed and whether runners crossed before the wickets were broken. Strike allocated accordingly.
No-Ball & Free Hit Carryover Law 21.19 Free-hit status auto-engages. If the free-hit delivery is a Wide or another No-Ball, the free-hit status persists to the next legal ball.
Bowler Spell Quota Max 20% of total innings overs System validates overs bowled against match limit (e.g., 4 overs in T20). Prevents selection of an exhausted bowler.
Consecutive Overs Ban Law 17.6 Prevents assigning the same bowler to two consecutive overs from either end.

The OBS Overlay operates in zero-margin transparent mode. Graphic modes are triggered via the Graphics Director:

Always visible during play. Features batting team logo, live score, overs, striker stats with live strike beacon, non-striker, bowler spell, and ball-by-ball dots.

Fires GPU keyframe animations on trigger:

DRS / Third Umpire Graphic

Broadcast stinger reading "THIRD UMPIRE REVIEW" followed by the umpire's ruling: "DECISION: OUT / NOT OUT".

5. Dual-Approval Tournament Workflow & Points Table

The tournament module supports public team registration with an administrative review queue:

  • Public Registration URL: Allows external team captains to enter their squad details, jersey numbers, and upload team logos. Submissions enter Pending Verification.
  • Admin Vetting Desk: The tournament manager reviews player eligibility, inspects logos, and clicks Approve or Reject.
  • Direct Management Addition: Teams enrolled directly by the admin bypass verification and are immediately marked Approved.
  • Points Table Engine: Automatically updates points and Net Run Rate (NRR) as matches conclude: $$\text{NRR} = \left( \frac{\text{Runs Scored}}{\text{Overs Faced}} \right) - \left( \frac{\text{Runs Conceded}}{\text{Overs Bowled}} \right)$$
